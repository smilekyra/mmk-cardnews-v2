# Plan: 대전가면 꼭 가야 하는 빵집 Top 3

## Card Type
**List** — Top 3 큐레이션 형식. 각 빵집의 개성을 비교 소개하며 빵지순례 욕구를 자극하는 구성.

## Magazine Style
**POPEYE** ✅

**선정 이유**: 이 콘텐츠는 대전이라는 도시의 로컬 식문화를 소개하는 라이프스타일/음식/시티 테마다. POPEYE의 '웜 필름, 시티보이 감성, 캐주얼 컨피던스'가 빵집 순례 문화의 따뜻하고 트렌디한 분위기와 정확히 맞아 떨어진다. 젊은 빵지순례자 타깃에도 부합.

**Color Palette (POPEYE)**
```
Primary:    #1A1A1A (film black)
Background: #F7F4EE (warm white)
Cream:      #E8E0D0
Muted:      #B5A89A
Accent:     #D4563A  (따뜻한 오렌지-레드 — 빵의 색깔 연상)
```

## Image Art Direction Details

### card-01.png — Cover: 대전 빵집 거리
**Prompt Direction**:
- 레트로 느낌의 대전 빵집 골목 또는 진열대 외관
- 웜 골든아워 빛, 필름 그레인
- 유리창 너머 빵이 쌓인 느낌 또는 빵집 외관 간판
- 상단에 주체, 하단 1/3 어두운 그라디언트 텍스트 존
- POPEYE 감성: 따뜻한 필름, 캐주얼, 도시 느낌
- 색: 웜 크림/오렌지/골든

### card-02.png — 성심당: 튀김소보로
**Prompt Direction**:
- 튀김소보로빵 (fried soboro bun) 근접 촬영
- 바삭하게 튀겨진 황금빛 겉면, 쪼개진 단면 — 팥앙금 가득
- 웜 앰버/골든 라이트, 소프트 섀도
- 오래된 나무 트레이나 크래프트 페이퍼 위
- 상단에 빵 집중, 하단 어두운 그라디언트

### card-03.png — 몽심/하레하레: 페이스트리 플랫레이
**Prompt Direction**:
- 소금식빵, 피낭시에, 마들렌, 과일 타르트가 함께 놓인 테이블
- 오버헤드(직상방) 플랫레이 앵글
- 웜 크림색 테이블보 또는 대리석 배경
- 자연광 또는 부드러운 스튜디오 라이팅
- 하단 1/3 빈 공간 (텍스트 존)
- POPEYE 감성: 랩 필름, 따뜻한 그레이딩
